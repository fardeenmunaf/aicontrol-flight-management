# aisafe.app.aircontrol.console

**Air Control Monitoring Console** — for Flight Control Operators (FCO).

## Purpose

This module is the **console UI application** for Flight Control Operators. It provides real-time monitoring, simulation, and safety reporting:

### Flight Control Operator (FCO) (US122–US151)
- **List active flight plans** (US122)
- **Monitor air control areas** in real time (US125)
- **Run the air control simulation** — launches the hybrid Java/C engine (US151)
- Consult **safety violation reports** generated by the simulation
- Act as the **TCP server** receiving data from Weather Clients and Pilots

## Structure

```
presentation/
├── MainMenu.java
├── monitoring/     ← real-time air control monitoring UIs
└── simulation/     ← simulation launcher and report viewer UIs
AirControlApp.java  ← main() entry point
tcp/                ← TCP server for remote client connections
```

## Dependencies

- `aisafe.core` — domain model + application services
- `aisafe.persistence.impl` — JPA repositories
- `aisafe-simulation` — launches the C simulation engine as a subprocess
